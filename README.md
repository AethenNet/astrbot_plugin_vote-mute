# AstrBot 投票禁言插件

> QQ 群投票禁言插件 — 让群成员通过投票决定是否禁言指定用户

**插件名称：** `astrbot_plugin_vote-mute`

**版本：** 1.0.0

**支持平台：** aiocqhttp（OneBot v11）

---

## 功能介绍

本插件为 QQ 群提供投票禁言功能，群成员可以发起对指定用户的禁言投票，其他成员通过发送指令参与投票。当同意人数达到设定上限时，投票立即通过并执行禁言；投票超时后根据配置决定是否执行禁言。

### 核心特性

- ✅ **投票禁言**：群成员可发起对指定用户的禁言投票
- ✅ **独立前缀开关**：发起投票与投票动作（同意/反对）可分别设置是否需要 `/` 前缀
- ✅ **多群独立配置**：每个群可单独配置参数，未配置的群使用默认配置
- ✅ **管理员介入**：可配置群管理员/群主投同意票直接禁言、投反对票直接取消
- ✅ **冷却时间**：可设置投票结束后的冷却时间，管理员/群主无视冷却
- ✅ **超时策略**：可配置投票超时未达上限时是否直接禁言

## 指令列表

| 指令 | 说明 | 示例 |
|------|------|------|
| `投票禁言 <@用户/QQ号> <分钟>` | 发起对指定用户的禁言投票 | `/投票禁言 @某人 10` |
| `同意禁言` | 投同意票 | `/同意禁言` |
| `反对禁言` | 投反对票 | `/反对禁言` |
| `投票禁言帮助` | 查看使用帮助 | `/投票禁言帮助` |
| `本群投票禁言配置` | 查看当前群的配置 | `/本群投票禁言配置` |

> 指令是否需要 `/` 前缀取决于插件设置中的两个独立开关。

---

## 配置说明

### 全局配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `start_vote_prefix` | bool | `true` | 发起投票禁言是否需要 `/` 前缀（包含投票禁言、投票禁言帮助、本群投票禁言配置） |
| `vote_action_prefix` | bool | `true` | 同意禁言和反对禁言是否需要 `/` 前缀 |

### 群配置（默认配置 + 各群独立配置）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `max_participants` | int | `5` | 投票通过所需的参与人数上限（同意人数达到此值立即通过），滑动范围 2-50 |
| `vote_duration` | int | `60` | 投票时长（秒），滑动范围 10-600 |
| `admin_intervene_ban` | bool | `false` | 群管理员、群主投同意票时是否直接禁言 |
| `admin_intervene_cancel` | bool | `false` | 群管理员、群主投反对票时是否直接取消投票 |
| `ban_on_timeout` | bool | `false` | 投票超时且同意数未达上限时是否直接禁言 |
| `cooldown` | int | `0` | 投票结束后的冷却时间（秒），0 表示无冷却；管理员/群主无视冷却，滑动范围 0-3600 |

## 工作流程

1. **发起投票**：群成员发送 `投票禁言 @用户 分钟数` 发起投票
   - 机器人检查自身是否有群管理员权限
   - 检查是否已有进行中的投票
   - 检查冷却时间（管理员/群主无视）
   - 发起人默认投同意票
   - 启动倒计时

2. **参与投票**：群成员发送 `同意禁言` 或 `反对禁言`
   - 管理员/群主介入（如已开启）：立即结算
   - 普通群员：记录投票，更新计数
   - 同意数达上限：立即通过并执行禁言

3. **投票结算**
   - 同意数达上限 → 执行禁言
   - 超时 + 开启超时禁言 → 执行禁言
   - 超时 + 未开启超时禁言 → 不执行禁言
   - 管理员介入禁言 → 执行禁言
   - 管理员介入取消 → 不执行禁言
   - 结算后进入冷却时间（如已配置）

## 安装方法

1. 将插件文件夹 `astrbot_plugin_vote-mute` 放入 AstrBot 的 `data/plugins/` 目录
2. 在 AstrBot 管理面板中启用插件
3. 根据需要在插件设置中配置参数
4. 确保机器人在目标 QQ 群中拥有管理员权限

---

## 注意事项

- 机器人必须拥有群管理员权限才能执行禁言操作
- 群主和管理员的角色通过 OneBot API 实时查询
- 普通群员无法触发管理员介入功能，即使相关开关已开启
- 投票数据存储在内存中，插件重载或重启后进行中的投票会丢失
- 建议配合群规使用，避免滥用投票禁言功能
